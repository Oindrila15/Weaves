## What MCP is
Model Context Protocol: a standard way to connect AI apps to tools and data, so each system needs one server and not a custom link per app. Think of a universal plug.
- **Server**: exposes capabilities. **Client**: lives in the app (Claude Code, your code) and talks to one server.
- A server offers three kinds of things:
  | Kind | What it is | Weaves example |
  |---|---|---|
  | **Tools** | Actions Claude can call | `get_weave_price` |
  | **Resources** | Data to read, like a catalogue | `weaves://catalog` |
  | **Prompts** | Reusable prompt templates | "Summarise this weaver profile" |
- **Transports**: `stdio` (the client starts the server as a local subprocess; what we ran) or HTTP (a remote server).
- The client asks the server what it offers (`list_tools`). Tool names and descriptions come from the server's code (here the docstrings), so Lesson 2.1 applies: write them well.

## Configuration in Claude Code
- **Project** `.mcp.json`: shared through git. Use `${ENV_VAR}` for secrets. Never put a key or password in the file.
- **Personal** `~/.claude.json`: yours only, not shared.
- All configured servers' tools are available at once, so every server adds to the tool count (see 2.3).
- **Resources expose catalogues** (issue lists, schemas) so the agent does not search blindly.
- Prefer an existing community server for a standard system (GitHub, Slack, a database). Write your own for your own logic.

## Errors over MCP
Result has `isError` (`is_error` in Python SDK v2). Use the same categories as 2.2. In SDK v2, raise `ToolError` for an anticipated failure so your message reaches the client. Any other exception is treated as a crash and the client only gets a generic message.

## CCA-P 3.7: which connection?
(Our reading, to verify.) MCP when several apps or agents share one capability and you want standard discovery and permissions. A direct API call or an existing CLI when one program needs one simple thing. Agent-to-agent when delegating a whole job to another autonomous agent that reasons on its own.
