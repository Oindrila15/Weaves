# Weaves knowledge repository

This folder holds everything Weaves knows and every rule it follows. The chatbot will search it, and people can read it.

- `policies/` holds the rules: what we may collect, how we trust sources, what the chatbot may say, how we spend money.
- `weaves/` (to come) will hold the weave pages: material, technique, region, official recognition, each with sources.

## How to keep it current

1. Every policy file starts with **Last checked** and a **Review when** line.
2. When a rule changes, or a source's terms change, edit the policy file and add one line to `CHANGELOG.md`.
3. Policies are decisions made by Claude from best practice and the sources linked in each file. They are **not legal advice**. Items marked "legal check" need a lawyer before launch.
