# Weaves

Weaves connects saree lovers, buyers and curious readers to handloom weavers. It brings together information that is scattered today: the weave, the material, the weaver, the price range and how exclusive a saree is, with the source and trust level shown for every fact. It is a directory and knowledge base, not a shop.

Weaves is also a learn-by-building project for agentic architecture and the Claude Certified Architect - Foundations exam.
