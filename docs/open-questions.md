# Open questions

Decisions still to make before technical design starts.

1. **Starting weaves and regions.** Which weaves and weaver clusters come first (for example one or two regions only)?
2. **Languages.** English plus which regional language?
3. **Success targets.** What numbers count as success for the measures in the BRD?
4. **Weaver listing.** Weavers are listed by public profile link only, with no outreach. Is that enough for the first version?
5. **Influencers.** Would any creators agree to share their information with credit?
6. **Revenue.** Is Weaves free for now, or should we plan for featured listings, verification fees or something else?
7. **Form factor.** Website, app, WhatsApp, or a mix? To be decided after the requirements are agreed.
8. **Official exam guide.** Download Anthropic's official exam guide for the Claude Certified Architect - Foundations from the Anthropic Partner Academy and share the list of domains, so the learning plan matches it.
9. **Government sources.** Which official pages and datasets are usable? To be checked together at the start of the build.
10. **Meta's rules.** Check Meta's current developer terms for Instagram and Facebook before designing anything that reads their data.
11. **Search tool terms.** Check the terms of the web search tool the discovery agent will use.
12. **Photos.** Which open-licence sources do we use (for example Wikimedia Commons), and how do we record licence and credit?
13. **Map data.** Which approved source gives correct India boundaries, and what do Indian map rules require?
14. **Public contact details.** When a weaver posts their own number publicly, may we copy it? Get a lawyer's view before launch.
15. **Chatbot scope.** Which questions should it answer, and which should it decline?
